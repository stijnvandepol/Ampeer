**Goal:** A tag on `main` becomes the running site, with no inbound port and nobody logging in to the server.

**Architecture:** GitHub-hosted runners build three images and push them to GHCR; the LXC pulls what CI built and runs nothing else. nginx serves the static site and forwards `/api/` to Django on the same origin, so there is no preflight in the request path. Cloudflare Tunnel makes the outbound connection, so nothing listens from outside.

**Tech Stack:** Docker Compose v2, nginx 1.29, Postgres 16, cloudflared 2026.8.2, gunicorn 26.1, Python 3.12.

**Spec:** `docs/superpowers/specs/2026-08-21-deploy-design.md`

## Global Constraints

- **Every image is pinned by digest**, never by tag. A tag is a name somebody else can repoint, and `tests/test_pipeline_contract.py` already refuses an unpinned service container.
- **The LXC builds nothing.** The deploy job runs `pull`, `up -d`, `migrate`, and stops. No checkout, no `docker build`, no token that can read the repository.
- **No `.env` with real values in the repository.** `infra/.env.example` carries the nine names and no secrets; the deploy reads a file on the host.
- **Nine environment variables are required and none has a default**: `DJANGO_SECRET_KEY`, `DJANGO_ALLOWED_HOSTS`, `DJANGO_CORS_ALLOWED_ORIGINS`, `DJANGO_NUM_PROXIES`, `AMPEER_NEDU_PROFILE_PATH`, `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_HOST`. A missing one must stop the deploy before anything restarts.
- **No token and no IP address in any log kept longer than the row it describes.**
- **Do not touch the runner `web2`.** Registering, re-registering or deleting a runner is Stijn's, and it is out of bounds for every task here.
- Work on `feat/deploy`. Never commit directly to `main`.

## The multi-agent working model

The six rules that make concurrency safe, unchanged from the three plans before this one:

1. **A lane owns paths exclusively.** No two lanes write the same file.
2. **Implementation agents never run git.** The integration gate commits.
3. **Every lane runs its own verification command** and reports the output.
4. **Gates run after lanes.** Integration first, audit second.
5. **A lane may not run a tool that writes outside the files it owns.**
6. **A lane that cannot proceed without editing a file it does not own stops and reports.**

A seventh, specific to this subproject: **no lane starts, stops or reconfigures anything on a host.** `docker compose up` against the local daemon is allowed and expected; anything touching Proxmox, the tunnel credentials or a GitHub runner is not.

```python
"""The compose file is configuration, so it is read like code.

Nothing here starts a container. These are properties of the document, and they
are the properties that would otherwise be discovered on the host: an image that
moved under a tag, a port published to the world, a secret with a default.
"""

from __future__ import annotations

from pathlib import Path
from typing import Any

import pytest
import yaml

INFRA = Path(__file__).resolve().parent.parent / "infra"
COMPOSE = INFRA / "docker-compose.yml"
ENV_EXAMPLE = INFRA / ".env.example"

#: prod.py refuses to start without each of these. Kept here as a literal
#: rather than imported, so a test failure names the drift instead of hiding it
#: behind an import that follows the change.
REQUIRED_ENV = (
    "DJANGO_SECRET_KEY",
    "DJANGO_ALLOWED_HOSTS",
    "DJANGO_CORS_ALLOWED_ORIGINS",
    "DJANGO_NUM_PROXIES",
    "AMPEER_NEDU_PROFILE_PATH",
    "POSTGRES_DB",
    "POSTGRES_USER",
    "POSTGRES_PASSWORD",
    "POSTGRES_HOST",
)


def compose() -> dict[str, Any]:
    return yaml.safe_load(COMPOSE.read_text(encoding="utf-8"))


def service(name: str) -> dict[str, Any]:
    services = compose()["services"]
    assert name in services, f"no service {name!r}: {sorted(services)}"
    return services[name]


def test_the_stack_has_the_four_services_it_needs() -> None:
    assert set(compose()["services"]) == {"api", "web", "db", "tunnel"}


@pytest.mark.parametrize("name", ["web", "db", "tunnel"])
def test_every_prebuilt_image_is_pinned_by_digest(name: str) -> None:
    """A tag is a name somebody else can repoint.

    `web` is built from a Dockerfile in this repository and `api` likewise, so
    those carry a build stanza instead; what has to be pinned is anything
    pulled from a registry, including the base images inside those Dockerfiles,
    which Tasks 2 and 3 assert separately.
    """
    image = str(service(name).get("image", ""))
    assert "@sha256:" in image, f"{name} is not pinned by digest: {image!r}"


def test_nothing_publishes_a_port_to_the_world() -> None:
    """Cloudflare Tunnel makes an outbound connection, so nothing listens.

    A `ports:` entry here is how a stack that was designed to be unreachable
    quietly becomes reachable, and the person who adds one is usually
    debugging, not deploying.
    """
    offenders = [name for name, spec in compose()["services"].items() if spec.get("ports")]
    assert not offenders, f"services publishing ports: {offenders}"


def test_no_secret_has_a_default_in_the_compose_file() -> None:
    """`${VAR:-something}` is a default, and a default for a secret is a secret
    in the repository with extra steps."""
    text = COMPOSE.read_text(encoding="utf-8")
    for name in REQUIRED_ENV:
        assert f"${{{name}:-" not in text, f"{name} has a default in docker-compose.yml"
        assert f"${{{name}:=" not in text, f"{name} has a default in docker-compose.yml"


def test_the_example_names_every_variable_and_carries_no_value() -> None:
    """The example is the checklist somebody works from. A value in it is a
    value somebody will ship."""
    lines = [
        line
        for line in ENV_EXAMPLE.read_text(encoding="utf-8").splitlines()
        if line.strip() and not line.startswith("#")
    ]
    named = {line.split("=", 1)[0] for line in lines}
    assert set(REQUIRED_ENV) <= named, f"missing: {sorted(set(REQUIRED_ENV) - named)}"
    for line in lines:
        name, _, value = line.partition("=")
        assert value == "", f"{name} carries a value in .env.example"


def test_the_database_volume_survives_a_restart() -> None:
    """Without a named volume the first `docker compose down` takes every
    stored advice with it, and that is a data loss nobody would attribute to
    the compose file."""
    assert compose().get("volumes", {}), "no named volumes declared"
    mounts = [str(m) for m in service("db").get("volumes", [])]
    assert any("/var/lib/postgresql/data" in m for m in mounts), mounts


def test_the_profile_file_is_mounted_read_only() -> None:
    """It is somebody else's data under unconfirmed redistribution terms. A
    read-write mount is a way for this service to change it."""
    mounts = [str(m) for m in service("api").get("volumes", [])]
    profile = [m for m in mounts if "nedu" in m.lower() or "profile" in m.lower()]
    assert profile, f"the api service mounts no profile file: {mounts}"
    assert all(m.endswith(":ro") for m in profile), profile


def test_every_service_restarts_unless_stopped_on_purpose() -> None:
    for name, spec in compose()["services"].items():
        assert spec.get("restart") == "unless-stopped", f"{name}: {spec.get('restart')}"
```

```python
class HealthView(APIView):
    """Is this container able to answer, not merely alive.

    It opens the consumption profile, because that is the one thing a wrong
    mount breaks and the one thing nothing else notices: the settings require
    the path to be set, not the file to exist, and the provider is only called
    when an advice is computed. Without this a misconfigured deploy reports
    healthy and fails every visitor.

    It does no arithmetic and issues no query. A check that runs every thirty
    seconds and does real work is a load generator with a nice name.
    """

    throttle_classes: ClassVar[list[type]] = []

    def get(self, request: Request) -> Response:
        from advice.profiles import profile_provider

        try:
            profile_provider()
        except RuntimeError:
            # Deliberately without the reason. This endpoint is unauthenticated
            # and reachable wherever the service is; a path on disk is not
            # something to hand out.
            return Response({"status": "unavailable"}, status=503)
        return Response({"status": "ok"})
```

Route it at `path("health/", HealthView.as_view(), name="advice-health")` in `backend/advice/urls.py`, **above** the token route, because `re_path` on 22 url-safe characters would otherwise be tried first and `health` is eight.

```python
"""nginx configuration read as text, because two lines in it decide whether the
product works and whether it keeps a promise the rest of the project enforces.

Nothing here starts nginx. These are properties of the file; Task 6 drives the
running server.
"""

from __future__ import annotations

import re
from pathlib import Path

CONF = Path(__file__).resolve().parent.parent / "infra" / "nginx" / "nginx.conf"
TEXT = CONF.read_text(encoding="utf-8")


def test_the_advice_route_falls_back_to_the_built_page() -> None:
    """The site is statically exported, so there is one built advice page and
    no route per token.

    Without this, the visitor who has just answered four questions gets a 404,
    not only the recipient of a shared link: the flow ends in a full navigation
    to /advies/<token>/. Their advice is computed, stored, and charged against
    their hourly budget, and they never see it.
    """
    block = re.search(r"location\s+/advies/\s*\{([^}]*)\}", TEXT, re.DOTALL)
    assert block, "no location block for /advies/"
    assert "try_files" in block.group(1)
    assert "/advies/index.html" in block.group(1)


def test_the_token_never_reaches_the_access_log() -> None:
    """The audit log stores the token hashed and no IP at all. nginx writing
    `client_ip "GET /api/advice/<token>/"` puts exactly the pairing this
    project refuses to make on disk, with a retention nobody here chose."""

    assert "access_log off" in body or re.search(r"access_log\s+\S+\s+\w+", body), body


def test_the_forwarded_headers_are_set_and_not_passed_through() -> None:
    """prod.py trusts X-Forwarded-Proto, which is only correct if the proxy
    overwrites it. DJANGO_NUM_PROXIES trusts the hop count in
    X-Forwarded-For, and a caller who can append to it can buy a fresh rate
    limit, which was measured on this API once already."""
    assert "proxy_set_header X-Forwarded-Proto $scheme;" in TEXT
    assert "proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;" in TEXT


def test_the_server_does_not_announce_its_version() -> None:
    assert "server_tokens off;" in TEXT


def test_nothing_is_proxied_except_the_api() -> None:
    """A proxy_pass outside /api/ is a way for the static site to become a
    forwarder to something nobody reviewed."""
    passes = re.findall(r"proxy_pass\s+([^;]+);", TEXT)
    assert all("api" in target for target in passes), passes
```

## Phase 3: three concurrent audits

Read-only. Each returns findings with a file, a line and a concrete failure scenario.

### Task 7: Audit lens one, what is reachable and what runs as whom

1. What listens, on what interface, in the production compose file and in the test override? Is there any path by which the override's published port reaches a host?
2. What runs as root? The API image says uid 10001; check nginx, Postgres and the tunnel, and say what each one could do if the process were taken over.
3. The tunnel token is an environment variable in a file on the host. What can somebody who reads that file do, and what would make it visible if they did?
4. GHCR: who can push to those two image names, and what stops a compromised workflow from publishing an image the LXC then pulls and runs? The deploy pulls by tag, not by digest — say whether that matters and what it would cost to fix.
5. `docker compose run --rm api python manage.py migrate` runs on the host as the runner's user. What else could that user do, and does the runner being non-ephemeral change the answer?

### Task 8: Audit lens two, does the deploy keep the privacy promises

1. Trace one request end to end and name every place the token is written: nginx access log, nginx error log, gunicorn log, Django log, Docker's json-file log driver, and the systemd journal. The access log is handled; find the others.
2. Same for the visitor's IP address. `DJANGO_NUM_PROXIES` implies the address is parsed; where does it end up?
3. Docker's default logging driver keeps container output until the container is removed, with no rotation. What is in it and how long does it live?
4. Postgres logs statements above a duration threshold by default in some images. Does this one, and would a statement carrying a token be logged?
5. The database volume survives `down`. What is the retention of a volume nobody deletes, and does that interact with the ninety day promise?
6. What does a backup of this stack contain, and has anybody said what its retention is?

### Task 9: Audit lens three, does it come up and stay up

1. Start the stack with each of the nine variables missing in turn. Does the preflight catch all nine, and is the error readable in each case?
2. Start it with `AMPEER_NEDU_PROFILE_PATH` pointing at a file that does not exist. Does the readiness check go unhealthy, and does the stack behave sensibly when it does?
3. Kill the database while the API is serving. What does a visitor see, and does it recover without intervention?
4. What happens on a deploy that pulls a broken image: does the old container stay up, or is there a window with nothing serving?
5. `migrate` runs on every deploy. What happens if two deploys overlap, and is there anything preventing that?
6. The healthcheck runs every thirty seconds and calls `profile_provider()`, which opens a file. Measure what that costs over a day and say whether it is worth it.
